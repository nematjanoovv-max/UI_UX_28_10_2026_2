What's inside

Everything you need to ship.

Built for real product work, not dribbble shots. Every screen is auto-layout, every component has variants, every token is named like a grown-up made it.

120 ready screens

Onboarding, auth, home, wallet, profile, settings and more. Each one responsive and ready to fork.

48 components

Buttons, inputs, cards, sheets, navs and tables with variants for every state you will actually need.

Token driven

Colour, type and spacing live in variables. Change one token, watch the whole kit follow.

Light & dark

Both themes are designed, not inverted. Every screen is checked for contrast in each mode.

Figma native

Auto layout, variables, component properties and styles. No detached layers hiding in the file.

Free updates
